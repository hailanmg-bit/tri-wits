# TriWits（博弈牌）

三人纸牌策略游戏：每回合三家同时盖牌比大小，再决定是否追加第二阶段。目标是做成面向全球（不含中国大陆）的手机游戏，支持 iOS 和 Android。

## 目录

| 路径 | 内容 |
|---|---|
| `src/app/` | App 外壳：对局驱动（电脑行动、限时代打）、本地存档、中英文文案 |
| `src/ui/` | 界面：牌桌（竖屏/横屏两套布局）、首页、闯关、设置、结算；当前为经典风皮肤 |
| `src/engine/` | 规则引擎（TypeScript，不依赖界面，客户端和以后的对战服务器共用） |
| `src/engine/ai/` | 6 种电脑策略，以及它们共用的牌力分析工具 |
| `tests/` | 规则单元测试，和旧版引擎逐步比对的一致性测试 |
| `src/game/levels.ts` | 闯关模式：30 关配置、对局安排、胜负判定；有“原版”和“模拟”两套对手顺序，默认用原版 |
| `scripts/sim.ts` | 电脑策略强弱模拟 |
| `legacy/` | 原网页版，仅供对照，不再维护 |

## 常用命令

```bash
npm install
npm run dev         # 本机浏览器预览（网址加 ?dev=1 显示开发者设置）
npm run dev:lan     # 同一 Wi-Fi 下用手机打开终端里显示的 Network 地址
npm test            # 规则测试 + 与旧版引擎的一致性测试
npm run typecheck
npm run sim -- 40   # 每个策略对阵其余策略，每个座位 40 局
```

## 规则要点

- 一副 54 张（含大小王），3 人各 18 张。得分 = 基础分 + 自己牌堆的张数；最先打空手牌的人（同一回合同一阶段可并列）得 5 分基础分。
- 第一阶段（必出）：有手牌的人各出 3 张盖牌，同时亮牌比大小，最大者赢走全部。
- 第二阶段（自愿）：至少 2 人参与才开启，必须出第一阶段最弱一手的牌型；如果第一阶段是非同花 235 赢了三条，则改为单张。牌型不符算无效；全部无效时，各家出的 3 张计入自己的牌堆。
- 牌型从大到小：三条 > 同花顺 > 同花 > 顺子 > 对子 > 单张。A23 是最小的顺子，QKA 是最大的，K-A-2 不算顺子。
- 王是万能牌，同牌型同点数时大王 > 小王 > 无王；花色 ♠ > ♥ > ♣ > ♦。
- 非同花 235：和三条同场时最大，否则最小。
